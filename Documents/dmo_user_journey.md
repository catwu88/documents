# DMO CMS用戶旅程設計

## 1. 用戶角色定義

### 1.1 主要用戶角色

#### **DMO管理員 (Primary Admin)**
- **角色描述**: 負責整體平台營運、策略決策、活動規劃
- **核心目標**: 提升目的地知名度、優化商家推廣效果、制定行銷策略
- **技術水平**: 中等，熟悉基本數位工具和管理系統
- **使用頻率**: 每日使用，平均2-3小時
- **關鍵需求**: 儀表板監控、活動管理、策略分析

#### **內容編輯員 (Content Editor)**
- **角色描述**: 負責商家資料維護、內容編輯、審核管理
- **核心目標**: 快速、準確地管理商家資訊，確保內容品質
- **技術水平**: 中等，熟悉內容管理系統和Excel操作
- **使用頻率**: 每日使用，平均4-6小時
- **關鍵需求**: 批次處理、內容編輯、狀態管理

#### **數據分析師 (Data Analyst)**
- **角色描述**: 負責數據監控、效果分析、策略建議、報表生成
- **核心目標**: 提供數據洞察，優化營運策略，制定KPI追蹤
- **技術水平**: 高，熟悉數據分析工具和統計方法
- **使用頻率**: 每週重度使用，每日輕度監控
- **關鍵需求**: 深度分析、報表生成、趨勢預測

## 2. DMO管理員用戶旅程

### 2.1 整體營運管理旅程

#### **場景**: 季度營運回顧與策略調整

```
階段1: 數據回顾 → 階段2: 問題識別 → 階段3: 策略調整 → 階段4: 執行監控
```

#### **詳細旅程地圖**

| 階段 | 用戶行為 | 觸點 | 用戶情緒 | 痛點 | 機會點 |
|------|----------|------|----------|------|--------|
| **認知階段** | 查看儀表板總覽 | 登入系統 → 儀表板 | 😐 中性 | 數據太多，不知道重點 | 智能摘要推薦 |
| **探索階段** | 深入分析具體數據 | 點擊各項指標 → 詳細報表 | 🤔 專注 | 需要在多個頁面間切換 | 統一分析界面 |
| **決策階段** | 識別表現不佳的商家 | 商家排行榜 → 篩選功能 | 😟 擔憂 | 不清楚改善方向 | AI推薦改善建議 |
| **行動階段** | 調整商家推廣策略 | 編輯商家標籤 → 活動規劃 | 💪 積極 | 操作步驟繁瑣 | 批次操作功能 |
| **監控階段** | 追蹤調整效果 | 定期查看數據變化 | 😊 滿意 | 缺乏實時警報 | 智能通知系統 |

#### **關鍵時刻 (Moments of Truth)**

**🎯 關鍵時刻1: 首次登入儀表板**
- **期望**: 一眼看懂整體狀況
- **現實挑戰**: 信息過載，不知道從何開始
- **設計解決方案**:
  ```
  智能儀表板設計:
  ├── 核心KPI卡片 (4個關鍵指標)
  ├── 今日重點提醒 (3個待處理事項)
  ├── 趨勢圖表 (30天數據對比)
  └── 快捷操作區 (最常用功能)
  ```

**🎯 關鍵時刻2: 發現商家表現下滑**
- **期望**: 快速找到原因和解決方案
- **現實挑戰**: 數據分散，分析耗時
- **設計解決方案**:
  ```
  智能診斷系統:
  ├── 自動識別異常指標
  ├── 提供可能原因分析
  ├── 推薦具體改善行動
  └── 一鍵執行改善措施
  ```

### 2.2 季節活動規劃旅程

#### **場景**: 規劃"大稻埕煙火季"活動

```
準備階段 → 規劃階段 → 執行階段 → 評估階段
```

**🔄 詳細流程**:

**階段1: 活動準備 (1週前)**
1. **登入系統** → 檢查去年同期數據
2. **分析歷史表現** → 識別成功關鍵因素
3. **查看商家分布** → 了解區域商家現況

*用戶心聲*: *"希望能快速看到去年活動的完整報告，不要讓我到處找資料"*

**階段2: 活動規劃 (3天內)**
1. **創建新活動** → 設定基本資訊
   ```
   填寫項目:
   ├── 活動名稱: 大稻埕煙火季2025
   ├── 活動期間: 2025/10/01 - 2025/10/31
   ├── 活動描述: [富文本編輯器]
   └── 主視覺上傳: [圖片上傳]
   ```

2. **設定地理範圍** → 在地圖上框選區域
   ```
   地圖操作:
   ├── 搜索"大稻埕" → 自動定位
   ├── 繪製活動範圍 → 多邊形工具
   ├── 調整邊界 → 拖拽控制點
   └── 預覽覆蓋商家 → 即時顯示數量
   ```

3. **選擇參與商家** → 批次選取和個別調整
   ```
   商家選擇界面:
   ├── 地圖視圖: 視覺化顯示所有商家位置
   ├── 列表視圖: 表格形式詳細資訊
   ├── 篩選功能: 依類型、評分、狀態篩選
   └── 批次操作: 全選、反選、條件選擇
   ```

*用戶心聲*: *"地圖操作要簡單直觀，最好能像Google Maps一樣好用"*

**階段3: 活動執行 (活動期間)**
1. **監控活動表現** → 即時數據追蹤
2. **調整推廣策略** → 基於數據優化
3. **處理突發狀況** → 快速響應機制

**階段4: 活動評估 (活動後)**
1. **生成活動報告** → 自動化報表
2. **分析成效數據** → ROI計算
3. **記錄經驗教訓** → 知識管理

## 3. 內容編輯員用戶旅程

   多維度分析工具:

**上午10:30 - 趨勢分析**

- **分析師**: 建立追蹤指標和基準

- **即時數據共享**: 三個角色都能看到實時數據
